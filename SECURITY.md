# Security policy

## Supported versions

Security fixes are provided for the latest BareTOC release. Users should update to the newest available version before reporting or retesting an issue.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability.

Email [admin@sitefueler.com](mailto:admin@sitefueler.com?subject=BareTOC%20security%20report) with “BareTOC security report” in the subject. Include the affected version, vulnerability type, prerequisites, minimal reproducible steps, likely impact, and a safe proof of concept. Do not send live exploits, malware, private keys, full datasets, or unnecessary personal information through ordinary email.

SiteFueler aims to acknowledge a credible report within three business days. Remediation time depends on severity, reproducibility, dependencies, and release risk. Please allow reasonable time for investigation and a coordinated fix before public disclosure.
